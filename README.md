# Trinh Vuong personal website

Prepared for https://trinhvg.github.io with the existing academic homepage, photos, and research stickers.

## Publish

Use the GitHub account `trinhvg`. Create or use its repository named `trinhvg.github.io`.
Upload this directory's contents to the repository. In Settings > Pages, select Deploy from a branch, branch `main`, folder `/docs`, and Save.

## Update

Edit `content.json` for publications and news; edit `template.html` for the profile and bio. Run `python3 build.py`, then commit the changed sources and generated `docs/index.html`. Styles, publication-tab behavior, and images are in `docs/`.

The website contains 19 publication entries organized into Journal, Conference, and Preprint tabs. Photos were provided by Trinh; the two decorative stickers were generated for this site.

Setup reference: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
